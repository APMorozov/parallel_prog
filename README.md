# Лабораторная работа 1: Перемножение квадратных матриц

## Что было сделано

В рамках лабораторной работы была разработана программа на языке C++, выполняющая:

- генерацию двух квадратных матриц заданного размера со случайными значениями;
- сохранение исходных матриц в файлы;
- перемножение матриц классическим алгоритмом;
- измерение времени выполнения операции;
- сохранение результирующей матрицы в файл;

Дополнительно реализована автоматическая верификация результатов:

- разработан Python-скрипт с использованием библиотеки `numpy`;
- выполняется сравнение результата C++ с эталонным результатом Python;
- C++ программа автоматически запускает Python-скрипт;
- при несовпадении результатов программа аварийно завершается.

---

## Структура проекта

### `main.cpp`

Основная программа на C++, выполняющая:
- генерацию матриц;
- запись/чтение файлов;
- перемножение матриц;
- замер времени выполнения;
- запуск Python-скрипта для проверки корректности.

### `check.py`

Скрипт на Python, выполняющий:
- чтение матриц из файлов;
- вычисление произведения с помощью `numpy`;
- сравнение результатов с использованием `np.allclose`;
- вывод результата проверки (`True` / `False`).
