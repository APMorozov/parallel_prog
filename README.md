# Лабораторная работа №3

## Параллельное умножение матриц с использованием MPI

---

## Задание

Модифицировать программу из лабораторной работы №1 для параллельной работы с использованием технологии MPI. Провести серию экспериментов с различными размерами матриц (200, 400, 800, 1200, 1600, 2000) и различным количеством процессов (1, 2, 4, 8, 14).

---

## Ход работы

В ходе выполнения лабораторной работы исходная программа умножения матриц была модифицирована с использованием технологии MPI (Message Passing Interface).

Параллелизация была реализована путем распределения строк результирующей матрицы между процессами. Каждый процесс вычислял свою часть результирующей матрицы.

Для взаимодействия между процессами использовались следующие функции:

- `MPI_Init` — инициализация среды MPI  
- `MPI_Comm_size` — получение количества процессов  
- `MPI_Comm_rank` — получение номера процесса  
- `MPI_Bcast` — рассылка данных всем процессам  
- `MPI_Gather` — сбор результатов

## Анализ результатов

Анализ результатов показывает:

- Увеличение числа процессов приводит к уменьшению времени выполнения программы
- Наиболее значительное ускорение наблюдается при увеличении числа процессов до 4–8
- Для малых размеров матриц параллелизация малоэффективна

Причины наблюдаемых эффектов:

- накладные расходы на передачу данных между процессами
- синхронизация процессов
- конкуренция за ресурсы системы

Также можно отметить:

- хорошую масштабируемость при увеличении размера задачи
- снижение эффективности при увеличении числа процессов
